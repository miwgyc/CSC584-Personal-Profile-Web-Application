# Personal Profile Web Application

## 1. Project Information
- **Course:** CSC584
- **Assignment:** Individual Assignment 1
- **Project Title:** Personal Profile Web Application

## 2. Project Description
This project is a simple web application that allows students to enter their personal information through an HTML form. The submitted information is processed by a Java Servlet using the HTTP POST method and displayed on a JSP page.

## 3. Technologies Used
- HTML
- CSS
- Java Servlet
- JavaServer Pages (JSP)
- NetBeans IDE
- GlassFish Server
- Java EE 7

## 4. Application Features
- Enter full name
- Enter student ID
- Enter programme
- Enter email address
- Enter hobbies
- Write a short self-introduction
- Submit personal information using HTTP POST
- Display submitted information on a JSP page

## 5. Project Structure
- `index.html` – Personal information form
- `ProfileServlet.java` – Processes submitted form data
- `profile.jsp` – Displays the submitted personal information
- `style.css` – Styles the application interface

## 6. How to Run the Application
1. Open the project using NetBeans IDE.
2. Configure GlassFish Server.
3. Right-click the project and select **Run**.
4. The personal profile form will open in the browser.
5. Fill in the required information.
6. Click **Submit Profile** to display the submitted information.
